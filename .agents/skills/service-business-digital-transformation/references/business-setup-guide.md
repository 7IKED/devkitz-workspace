## Überblick

### Ziele

1. **Lokale Sichtbarkeit:** Top 3 Rankings für lokale Keywords
2. **Kundengewinnung:** Mehr Anrufe und Anfragen
3. **Vertrauensaufbau:** Positive Bewertungen und Reputation
4. **Professionelle Präsenz:** Moderne Website und Social Media
5. **Nachhaltiges Wachstum:** Langfristige Kundenbeziehungen

### Timeline

- **Phase 1 (Woche 1-2):** Grundlagen
- **Phase 2 (Woche 3-4):** SEO-Setup
- **Phase 3 (Woche 5-8):** Lokale Präsenz
- **Phase 4 (Woche 9-12):** Content & Marketing
- **Phase 5 (Monat 4+):** Monitoring & Optimierung

## Phase 1: Grundlagen (Woche 1-2)

### Aufgabe 1.1: Webseite überprüfen

**Checkliste:**

- [ ] Domain ist aktiv und erreichbar
- [ ] SSL-Zertifikat ist installiert (https://)
- [ ] Website ist mobil-responsive
- [ ] Ladegeschwindigkeit ist gut (< 3 Sekunden)
- [ ] Alle Kontaktinformationen sind korrekt
- [ ] Öffnungszeiten sind aktuell
- [ ] Call-to-Action Buttons sind sichtbar
- [ ] Keine 404-Fehler

**Ressourcen:**
- Google PageSpeed Insights: https://pagespeed.web.dev
- Mobile-Friendly Test: https://search.google.com/test/mobile-friendly

### Aufgabe 1.2: Geschäftsinformationen sammeln

**Zu sammeln:**

- [ ] Offizielle Geschäftsname
- [ ] Vollständige Adresse
- [ ] Telefonnummer(n)
- [ ] E-Mail-Adresse(n)
- [ ] Website-URL
- [ ] Öffnungszeiten
- [ ] Servicegebiet
- [ ] Geschäftsbeschreibung (max. 750 Zeichen)
- [ ] Logo (PNG mit transparentem Hintergrund)
- [ ] Hochwertige Fotos (mindestens 10)
- [ ] Zertifikate & Qualifikationen
- [ ] Versicherungsinformationen

### Aufgabe 1.3: Google-Konto vorbereiten

**Schritte:**

- [ ] Google-Konto erstellen (falls nicht vorhanden)
- [ ] Zwei-Faktor-Authentifizierung aktivieren
- [ ] Wiederherstellungs-E-Mail hinzufügen
- [ ] Telefonnummer hinzufügen

**Wichtig:** Nutze ein Geschäftskonto, nicht persönlich!

### Aufgabe 1.4: Lokale Keywords recherchieren

**Keywords für Liebevolle Hände:**

**Primäre Keywords:**
- Betreuungsdienst Bad Honnef
- Seniorenpflege Bad Honnef
- Altenpflege Bad Honnef
- Betreuung Senioren Bad Honnef

**Sekundäre Keywords:**
- Haushaltshilfe Bad Honnef
- Demenzbetreuung Bad Honnef
- Entlastung Angehörige Bad Honnef
- Begleitung Arztbesuche Bad Honnef

**Lokale Varianten:**
- Betreuungsdienst Rheinbreitbach
- Seniorenpflege Aegidienberg
- Altenpflege Rheinbreitbach

**Tools:**
- Google Keyword Planner: https://ads.google.com/intl/de_de/home/tools/keyword-planner/
- Google Search Console: https://search.google.com/search-console
- Ubersuggest: https://ubersuggest.com

## Phase 2: Suchmaschinen-Optimierung (Woche 3-4)

### Aufgabe 2.1: Google Search Console einrichten

**Schritte:**

- [ ] Google Search Console öffnen: https://search.google.com/search-console
- [ ] Webseite hinzufügen
- [ ] Webseite verifizieren (HTML-Tag oder DNS)
- [ ] Sitemap einreichen
- [ ] robots.txt überprüfen
- [ ] Mobile Usability überprüfen
- [ ] Indexierungsstatus überprüfen
- [ ] Alerts aktivieren

**Zeitaufwand:** 30-45 Minuten

**Ressourcen:**
- [Google Search Console Anleitung](/home/ubuntu/upload/recovery/Google_Search_Console_Anleitung.md)

### Aufgabe 2.2: Bing Webmaster Tools einrichten

**Schritte:**

- [ ] Bing Webmaster Tools öffnen: https://www.bing.com/webmasters
- [ ] Webseite hinzufügen
- [ ] Webseite verifizieren
- [ ] Sitemap einreichen
- [ ] Crawl-Einstellungen konfigurieren

**Zeitaufwand:** 20-30 Minuten

**Ressourcen:**
- [Bing Webmaster Tools Anleitung](/home/ubuntu/upload/recovery/Bing_Webmaster_Tools_Anleitung.md)

### Aufgabe 2.3: Google Analytics einrichten

**Schritte:**

- [ ] Google Analytics öffnen: https://analytics.google.com
- [ ] Konto erstellen
- [ ] Property erstellen
- [ ] Tracking-Code in Website einfügen
- [ ] Ziele definieren (Anrufe, Kontaktformular, etc.)
- [ ] Konvertierungen tracken

**Wichtige Ziele:**
- Anrufe (Telefonnummer Klicks)
- Kontaktformular Einreichungen
- Website-Besuche
- Seiten pro Besuch
- Durchschnittliche Besuchsdauer

**Zeitaufwand:** 45-60 Minuten

### Aufgabe 2.4: Meta-Tags optimieren

**Zu überprüfen/Optimieren:**

- [ ] Title Tag (50-60 Zeichen)
- [ ] Meta-Beschreibung (120-160 Zeichen)
- [ ] Keywords Meta-Tag
- [ ] Canonical URL
- [ ] Open Graph Tags
- [ ] Twitter Cards
- [ ] Structured Data (Schema.org)

**Beispiel Title Tag:**
```
Betreuungsdienst Liebevolle Hände - Empathie mit Herz
```

**Beispiel Meta-Beschreibung:**
```
Betreuungsdienst in Bad Honnef - Liebevolle Betreuung für Senioren 
und Pflegebedürftige mit Herz.
```

**Zeitaufwand:** 30-45 Minuten

- Freitag: Team-Vorstellung

**Woche 3:**
- Montag: Sicherheits-Tipp
- Mittwoch: Aktuelle Nachrichten
- Freitag: Kundenbewertung

**Woche 4:**
- Montag: Wellness-Tipp
- Mittwoch: Spezialangebot
- Freitag: Erfolgsgeschichte

**Zeitaufwand:** 2-3 Stunden

### Aufgabe 4.2: Social Media aufbauen

**Plattformen:**

- [ ] Facebook Business Seite erstellen
- [ ] Instagram Business Account erstellen
- [ ] LinkedIn Company Page erstellen
- [ ] Twitter Account erstellen (optional)

**Pro Plattform:**
- [ ] Profil ausfüllen
- [ ] Profilfoto hochladen
- [ ] Beschreibung schreiben
- [ ] Website verlinken
- [ ] Öffnungszeiten eintragen
- [ ] Kontaktinformationen hinzufügen

**Zeitaufwand:** 2-3 Stunden

### Aufgabe 4.3: Beiträge erstellen

**Beitragstypen:**

1. **Tipps & Ratschläge** (1-2 pro Woche)
2. **Veranstaltungsankündigungen** (1 pro Monat)
3. **Team-Vorstellungen** (1 pro Monat)
4. **Kundengeschichten** (1 pro Monat)
5. **Aktuelle Nachrichten** (1 pro Woche)

**Beitrags-Template:**

```
Titel: [Aussagekräftiger Titel]
Beschreibung: [100-300 Zeichen]
Bild: [Hochwertige Grafik oder Foto]
Call-to-Action: [Jetzt anrufen / Termin vereinbaren / Mehr erfahren]
Keywords: [Relevante Keywords]
```

**Zeitaufwand:** 30 Minuten pro Beitrag

### Aufgabe 4.4: E-Mail-Marketing aufbauen

**Schritte:**

- [ ] E-Mail-Marketing-Tool auswählen (z.B. Brevo, Mailchimp)
- [ ] E-Mail-Liste aufbauen
- [ ] Newsletter-Vorlage erstellen
- [ ] Willkommens-E-Mail schreiben
- [ ] Monatliche Newsletter planen
- [ ] Automatische E-Mail-Sequenzen einrichten

**Newsletter-Inhalte:**
- Tipps für Senioren
- Unternehmens-News
- Spezialangebote
- Kundengeschichten
- Veranstaltungsankündigungen

**Zeitaufwand:** 3-4 Stunden
