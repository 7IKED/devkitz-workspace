## Kern-Stil: Crystal Clear Glassmorphism

**NICHT milchig. NICHT frosted. KRISTALLKLAR.**

Wie Swarovski Optical Crystal — komplett transparent, Form NUR durch Lichtinteraktionen sichtbar:

| Effekt | Beschreibung |
|:-------|:-------------|
| **Specular Reflections** | Rasiermesser-scharfe weisse Lichtstreifen auf polierten Flaechen |
| **Fresnel Edge Highlights** | Duenne leuchtende Umrisslinien an JEDER Kante — definiert die Wireframe-Form |
| **Refraction Distortion** | Sichtbare Lichtbrechung durch Glasdicke — Objekte dahinter erscheinen leicht verschoben |
| **Caustic Patterns** | Lichtkonzentrationen wo Glas als Linse wirkt — helle Brennpunkte |
| **Total Internal Reflection** | Licht springt in duennen Glasstaeben hin und her wie Glasfaser |

## Material-Spezifikation

```
Material: Schott BOROFLOAT 33 Borosilicate Glass
IOR: 1.52 (Brechungsindex)
Abbe: 65 (niedrige Dispersion)
Absorption: 0 (farblos)
Oberflaeche: Mirror-polished, keine Aetzung
Farbe: Weiss-Silber monochrom (nur Lichtinteraktionen)
```

## Lighting Setup

```
Key Light: 5600K Tageslicht, Position 2 Uhr (60deg), Elevation 45deg
Fill Light: 4200K leicht warm, Position 8 Uhr (240deg), 12% Intensitaet
Ambient: KEINS — Dunkelheit wo kein Licht hinfaellt
```

## Rendering

```
Path-traced: 512 samples per pixel
Max Bounces: 12 (fuer Glass-Caustics)
Tone Mapping: Filmic sRGB
Post-Processing: KEIN kuenstlicher Bloom/Glow
Format: PNG mit Alpha-Kanal (transparent)
```
