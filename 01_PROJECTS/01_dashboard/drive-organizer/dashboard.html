API Key holen

Öffne die Google Cloud Console und erstelle einen API Key:

1. Klick auf den Button unten
2. Wähle oder erstelle ein Projekt
3. Klick "API-Schlüssel erstellen"
4. Kopiere den Schlüssel
5. Aktiviere die "Google Drive API"
