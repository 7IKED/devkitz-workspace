📖 Bedienungshandbuch

⚡ Capture — Schnell-Erfassung
  1. Text in das Eingabefeld tippen
  2. Typ auswaehlen: Notiz, Aufgabe, Idee, Lesezeichen, Snippet, Rust, C
  3. Optional: Tags kommagetrennt eingeben
  4. Enter druecken oder 'Speichern' klicken

Alle Eintraege werden sofort in localStorage gespeichert.

📚 Browse — Suchen & Filtern
  1. Suchbegriff eingeben — durchsucht Text und Tags
  2. Typ-Filter auswaehlen fuer gezielte Ergebnisse
  3. Klick auf Eintrag kopiert Text in Zwischenablage
🕸️ Graph — Knowledge Graph
  1. Zeigt alle Eintraege als Netzwerk-Knoten
  2. Gemeinsame Tags erzeugen Verbindungslinien
  3. 3 Cluster: DEVKiTZ Struktur, Second Brain, Playbook
  4. Nanobots schwirren zwischen Knoten und schliessen Luecken
🤖 Chat — KI Assistent
  1. Provider waehlen: GPT OSS 20B (vLLM), llama.cpp, Gateway, Ollama
  2. Frage eingeben — durchsucht lokale Eintraege + KI
  3. Offline-Modus: Funktioniert auch ohne API
  4. Qwen Embedding fuer semantische Suche aktiv
🦀 Code Lab — Rust & C Editor
  1. Sprache waehlen: Rust oder C
  2. Code schreiben im Editor
  3. 'Run' simuliert die Ausgabe
  4. 'Save' speichert als Snippet mit Name und Tags
🔌 Integrations — Externe Services
  1. GitNexus: Codebase-Graph oeffnen und navigieren
  2. Grafana: System-Monitoring starten
  3. Dashy: Homelab-Dashboard verbinden
  4. OpenDisplay: Layout und Theme anpassen
🧬 Open Human — Obsidian & Skills
  1. Vault-Pfad eingeben und Notizen importieren/exportieren
  2. LLM Skills aktivieren fuer KI-gestuetzte Textverarbeitung
  3. Backend waehlen: vLLM, llama.cpp, Gateway, Ollama, Lokal
